# Architecture Decision Records

Capture material engineering choices here.

## Format

Each ADR: `NNNN-short-title.md` (e.g. `0001-typescript-monorepo.md`).

Suggested sections:

1. **Status** — Proposed | Accepted | Superseded
2. **Context** — problem and constraints
3. **Decision** — what we chose
4. **Consequences** — tradeoffs and follow-ups
